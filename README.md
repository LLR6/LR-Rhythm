# 朝夕 · LR Rhythm

**把作息调到考场时间，把每一份微光留给自己。**

离线 Android 作息与状态记录应用 · 考研模板 · 可编辑时段 · 图片日记 · 签到成长 · 趋势回顾

</div>

## 为什么做朝夕

为2027考研前两个月的作息调整而设计：逐步接近22:30休息、6:30起床，在8:30与14:00主动练题，记录真实睡眠、困倦和咖啡因摄入。模板可以改成自己的学习、工作或生活节奏。

第一版不要求“完美执行”。部分完成和主动休息也可以留下记录；断签不会清空累计成长。

## 已实现

- **今日**：目标日倒计时、阶段提示、进度、接下来时段、每日签到、睡眠与咖啡因入口。
- **作息**：默认11个考研生活时段，自由增加、删除、修改时间/提示；按开始时间排序，支持跨午夜。
- **历史保护**：每日保存独立作息快照，改模板不覆盖历史；同步当天时保留已记录时段。
- **时段记录**：完成/部分完成/休息，心情与精力1–5、困倦0–10、实际专注分钟、心得、每时段最多4张照片。
- **图片**：系统图片选择器、本机压缩保存（长边最多1200px），支持回看和删除。
- **手记**：每日自由复盘，按日期查看历史。
- **趋势**：近7/30天记录、完成、专注、睡眠和心情统计；上午/下午困倦分组；有足够样本才展示睡眠分组比较。无记录不伪装为零分。
- **成长**：累计签到、连续/最长连续、微光等级、6枚徽章、本月日历回顾；重复签到不重复加分。
- **专注计时**：25/45/60分钟，时间戳恢复，结束时手动记入关联时段；不承诺后台计时响铃。
- **主题**：晨雾绿、晴空蓝、晚霞粉；昵称和目标日可改。
- **提醒**：3个可编辑的每日本地通知，默认关闭；Android13+请求通知权限。系统省电可能延迟，非精确闹钟。
- **备份**：系统文件界面导出/导入完整JSON，包含照片；校验格式，确认后替换，不与当前数据合并。

## 安装与日常使用

Android 8.0及以上，需要支持现代JavaScript的Android System WebView。安装签名APK后即可离线使用，无需账号。

1. 在「作息」修改模板；需要立即用于当天时，点「同步至这一天」。
2. 每个时段点「记录状态」或「打卡」，选择实际情况并保存。
3. 在「今日」记录起床当天的昨夜睡眠、咖啡因饮用量与时间。
4. 在「记录」回看心得照片，「趋势」观察变化，「成长」查看签到与徽章。
5. 在设置开启通知提醒；定期导出完整备份。

「签到」是每日到场记录；「时段打卡」需要保存实际状态。两者分开计算。未来日期仅预览，不提前记完成。历史日期允许补充生活记录，但每日签到仅当天可点。

## 数据与隐私

应用没有INTERNET权限、广告、账号、远端统计或个人信息上传。Android私有目录通过AtomicFile保存JSON；页面只加载APK内受限本地资源，禁用任意文件与远端页面加载。备份写入你选定的位置；照片会包含在备份内，请妥善保存。

**卸载会清除本机数据。请先导出。** Android系统自动备份默认关闭，避免用户误以为已拥有云端备份。手动导入会替换本机记录，建议先导出当前内容。导入支持最大24MB JSON；图片很多时请及时备份和精简。

## 开发与构建

技术：Android Java壳 + 本地HTML/CSS/JavaScript界面，无第三方运行时SDK、无前端构建依赖。共享`core.js`包含日期、统计、成长与备份校验逻辑。

需要JDK17、Android SDK35 / build-tools35.0.0。常规构建：

```bash
./gradlew assembleDebug
```

输出`app/build/outputs/apk/debug/`，调试包ID为`com.lr.rhythm.debug`；正式包ID为`com.lr.rhythm`。调试包与正式包可分别安装，数据独立。

若不使用Gradle插件，也可使用官方SDK工具链构建：

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export LR_KEYSTORE_PATH=/private/path/lr-rhythm-release.jks
export LR_KEYSTORE_PASSWORD='your-private-password'
export LR_KEY_ALIAS=lr-rhythm
bash scripts/build-apk.sh
```

正式版本升级必须使用同一签名密钥。**密钥与密码不要提交GitHub**；项目备份中单独的私有签名备份仅供所有者保管。`.gitignore`已排除密钥、安装包和构建输出。CI默认只生成独立调试包，不分发正式签名。

```bash

npx playwright install chromium
node tests/ui.test.cjs
```

可通过`CHROME_PATH`指定已有Chrome/Chromium路径。UI测试使用临时HTTP服务，覆盖签到幂等与重载、带图记录、文本转义、作息历史、睡眠/咖啡因统计、主题、专注恢复、备份恢复/拒绝无效备份、删除和320/393/768px布局。

当前交付已通过纯逻辑测试、浏览器交互检查及APK签名校验；尚未做Android真机验证。系统文件选择器、不同厂商通知策略、软键盘布局和省电后台行为仍需真机反馈。

## 健康信息边界

默认生活模板不是治疗方案。困倦评分是自我感受，统计是描述性观察，不能推断咖啡因或睡眠与成绩的因果关系。持续失眠、心悸或睡足仍明显嗜睡，请就医。

参考：研招网2027初试安排、CDC About Sleep、NIH/NHLBI Healthy Sleep Habits、FDA咖啡因科普、国家卫生健康委2026年5月25日发布会。具体考试安排以准考证、考点通知为准。
